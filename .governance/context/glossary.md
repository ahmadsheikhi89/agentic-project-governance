# Glossary

**APG** — Agentic Project Governance.  
**Governance** — authority, protected rules, precedence, and decision boundaries.  
**Policy** — a constraint that applies to work.  
**Workflow** — a repeatable procedure.  
**Context** — descriptive knowledge needed to understand the project.  
**Role** — responsibility boundary.  
**Adapter** — vendor/tool compatibility layer.  
**Evidence** — observable proof supporting a validation claim.  
**Scoped instruction** — instruction applying to a repository subtree.
