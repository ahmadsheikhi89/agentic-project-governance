# Conventions

- Core documentation uses Markdown.
- Machine-readable APG metadata uses YAML.
- Root framework version is stored in `VERSION`.
- Public releases use semantic versioning.
- Vendor-specific compatibility belongs in `adapters/`.
- `AGENTS.md` is an adapter/router, not the complete governance model.
- Consuming projects should remain minimal.
- Existing authoritative project sources should be referenced rather than copied.
- Optional APG extensions should be loaded only when relevant.
- Important rules are referenced from their canonical location rather than duplicated.
