# Examples

The examples demonstrate how the same APG core can be applied to different project types.

- `minimal/` — smallest useful APG governance footprint; no `PROJECT.md` required.
- `devops/` — infrastructure/operations example.
- `software/` — software product example.
- `hr/` — recruitment/HR example.
- `industrial-engineering/` — process-improvement example.

The domain examples intentionally keep a small `PROJECT.md` as one project source. This demonstrates that `PROJECT.md` is **allowed but optional**: the manifest may instead reference existing README, architecture, specifications, runbooks, or other project-native sources.

Examples are reference material, not a mandatory installation tree.
