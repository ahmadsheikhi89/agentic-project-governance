# Security Policy

## Reporting a security issue

Do not publish secrets, credentials, private keys, access tokens, or sensitive personal data in public issues.

For a security-sensitive finding, contact the repository maintainer through an appropriate private channel associated with the project owner before public disclosure.

## Supported version

The currently supported public release is:

```text
v1.0.x
```

## Governance security principles

- never store runtime secrets in governance files;
- do not disable security controls merely to satisfy validation;
- distinguish unverified assumptions from verified findings;
- preserve least-privilege boundaries;
- do not treat AI-generated output as security approval.
