# Changelog

All notable changes to Agentic Project Governance are documented here.

## [1.0.0] - 2026-08-19

### Initial public release

- vendor-neutral, repository-native APG governance model;
- explicit four-question core model:
  - authoritative sources;
  - applicable rules;
  - action authority;
  - validation evidence;
- `AGENTS.md` defined as an adapter/router rather than the complete governance model;
- `PROJECT.md` clarified as optional for consuming projects;
- manifest-based authoritative project source resolution;
- evidence-backed validation semantics;
- thin Codex, Claude Code, Gemini, and GitHub Copilot adapters;
- minimal and domain adoption examples;
- optional workflows, roles, templates, context helpers, and profiles;
- structural bootstrap and validation tooling;
- bilingual Persian/English documentation;
- GitHub Pages website at `apg.opspro.ir`.
